# Minor-language-learning-site-

The original purpose of this open-source package was to create a web app for my personal French learning needs. It allows users to filter high-quality movies and TV shows that have relevant subtitles and dubbing based on their chosen languages – in my case, French and English by default. After selecting a title, users can download the corresponding subtitles. In the future, I plan to integrate a one‑click search for BitTorrent links, so users can download the video files using those links and combine them with the subtitles they’ve downloaded. Since the API used is my own private one (which has usage limits), you can replace it with your own personal API from relevant websites. I hope this helps you.
